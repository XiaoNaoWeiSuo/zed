# 集成工具操作员

角色 ID 为 `integration`。公共封套、字段规则和权限边界见 [Infinity 协议](../INFINITY.md)。

完整设计的范围是 `{connector_id: id}`。每个已启用的集成操作由注册表提供固定的 `operation_id`、`input` 和结果类型，以及读写权限和批准要求。运行时把具体操作的字段投影到主提示词目录，因此模型可见的是实际契约。只读操作可无状态，复杂交互仅保留 job 内游标。

| 动作 | `args` | `data` |
| --- | --- | --- |
| `invoke` | `operation_id: id`、`input: object`，由该操作的注册 schema 校验 | `operation_id: id`、`receipt_ref: EvidenceRef`、`fields: object`，由该操作的注册结果 schema 校验 |

```text
你负责完成已注册的集成操作。使用目录中指定的操作和目标账号，按 schema 校验参数。将
返回字段、外部回执与推测分列，保留错误与覆盖缺口。操作有外部副作用时，使用运行时
绑定到本次请求的批准和回执。只向主模型返回目录允许的结果字段。
```

## 操作注册与结果校验

注册项包含连接器身份、操作版本、字段 schema、只读或写入分类和结果投影。更新 schema 时绑定新目录版本。账户或连接状态失效时返回 `denied` 或 `failed` 的明确原因。主模型发出的对象按已启用的具体操作校验，工具模型接收的是已识别的操作及授权目标。

只读操作可在预算内重试。写入操作需要可对账的回执，结果未知时先查询回执或外部状态。敏感字段由注册的结果投影移除。验收覆盖未知操作、版本不匹配、权限撤回、外部副作用确认和重复投递。

## 当前实现

当前实现为连接中的 MCP 服务提供 `list_operations` 和 `invoke`。浏览目录可读取工具附带的输入 schema。调用前重新获取 schema，校验参数并逐次征求界面批准。结构化或文本结果生成有界回执。跨文档 schema 引用、附件和非文本结果目前仅保留协议层限制。
