# 命令执行员

角色 ID 为 `command_runner`。公共封套、字段规则和权限边界见 [Infinity 协议](../INFINITY.md)。

完整设计的范围是 `WorkspaceScope`。首个实现只接受项目配置中经授权的构建或测试预设。进程句柄独立于模型，命令执行的副作用按进程而非提示词管理。短状态只关联当前 job 的进程、报告和输出游标。

| 动作 | `args` | `data` |
| --- | --- | --- |
| `run_preset` | `preset_id: id`、`parameters: {name: string, value: string}[]` | `run_ref: EvidenceRef`、`state: exited \| interrupted \| outcome_unknown`、`exit_code?: int`、`duration_ms: int`、`report_refs: EvidenceRef[]` |

```text
你负责运行指定预设并报告实际结果。先核对预设参数和项目范围。已运行的进程由其回执
追踪。根据退出状态和报告区分通过、失败、中断和未知。输出保存在执行侧，返回退出信息、
持续时间和报告引用。结束状态未知时交回运行时对账。
```

## 进程和回执

预设注册时声明命令、参数类型、工作目录、环境及可能副作用。检查参数只通过注册的字段，运行时负责生成进程参数和匹配批准。完成状态以实际退出或可信回执为准。取消和超时由运行时发出进程中断并确认，无法确认退出时返回 `outcome_unknown`。

原始 stdout 与 stderr 分开归档，报告适配器可提取结果及失败签名。回执绑定预设版本、工作区快照和尝试编号。恢复时优先查询已有进程状态，已完成的记录可以直接返回。验收区分正常退出、失败退出、超时、未确认取消和进程启动后中断。

## 当前实现

当前实现支持 `list_presets` 与 `run_preset`。先从项目任务清单发现可在工作区根目录直接执行的预设，参数来自配置，批准界面展示实际命令和参数。带自定义目录、环境覆盖、模板变量或需 shell 展开的预设暂不进入目录。命令输出有确定上限。失败结果可由小模型解释。
