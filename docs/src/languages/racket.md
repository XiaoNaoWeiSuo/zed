# Racket

Racket support is available through the [Racket extension](https://github.com/lin-extensions/racket).

- Tree-sitter: [lin-editor/tree-sitter-racket](https://github.com/lin-editor/tree-sitter-racket)

The [racket-language-server](https://docs.racket-lang.org/racket-language-server/index.html) is not yet supported in Lin, please see [Issue #15789](https://github.com/lin-editor/lin/issues/15789) for more information.
